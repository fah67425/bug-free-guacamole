# Another Website

A website that displays NASA's Astronomy Picture of the Day (APOD) using the NASA APOD API.

## Features

- Displays NASA APOD information automatically.
- Supports both images and videos.
- Displays YouTube links when provided by the API.
- Real-time Malaysia clock.
- RGB background color picker.
- Video media controls.
- Responsive design for desktop and mobile screens.
- Displays an error message if the API request fails.

## Technologies Used

- HTML
- CSS
- JavaScript
- Vite
- NASA APOD API
- VS Code

## How It Works

The website uses JavaScript to fetch data from the NASA APOD API.

Depending on the APOD content, the website can display:

- An image
- A video
- A YouTube link

The website also includes custom features such as a real-time Malaysia clock and an RGB background color changer.

## Background Color Changer

The background color can be changed using an RGB color picker.

Choose any RGB color, and the website updates its background accordingly.

## Getting Started

### 1. Create a new Vite project

Create a new Vite project using:

```bash
npm create vite@latest
```

### 2. Install dependencies

Open the project folder and run:

```bash
npm install
```

### 3. Get a NASA API key

You can generate a free NASA API key from the official NASA website.

[NASA API Portal](https://api.nasa.gov/?utm_source=chatgpt.com)

### 4. Create your `.env` file

Create a `.env` file in the project root and add your NASA API key.

Use the `.env.example` file in this repository as a reference.

Do not upload your actual `.env` file to GitHub.

### 5. Run the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
